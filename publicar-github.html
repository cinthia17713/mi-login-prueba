Cómo crear y publicar tu index.html en GitHub Pages

Crear y publicar tu archivo index.html en GitHub (para que sea visible en la web usando GitHub Pages) es muy sencillo. Tienes dos formas de hacerlo: directamente desde la página web de GitHub (más rápido si es un archivo suelto) o usando Git desde tu computadora.

Método 1: Desde la página web de GitHub (sin instalar nada)

Paso 1: Crear un nuevo repositorio

  1. Entra a GitHub e inicia sesión en tu cuenta.
  2. En la esquina superior derecha, haz clic en el botón + y selecciona New repository (Nuevo repositorio).
  3. Repository name: escribe el nombre que quieras (por ejemplo, mi-pagina-web).
  4. Selecciona la opción Public (Público) para que GitHub Pages sea gratuito y visible.
  5. ⚠️ Muy importante: marca la casilla Add a README file (Agregar un archivo README). Esto creará el repositorio con una rama base lista para usar.
  6. Haz clic en el botón verde Create repository.

Paso 2: Crear o subir tu archivo index.html

  1. Ya dentro de tu nuevo repositorio, haz clic en el botón Add file (Agregar archivo) y selecciona Create new file (Crear nuevo archivo).
  2. En el espacio donde dice Name your file..., escribe exactamente: 
    index.html
    (Asegúrate de que esté todo en minúsculas y sin acentos, ya que los servidores distinguen mayúsculas y minúsculas).
  3. Pega el código HTML de tu página en el editor de texto grande.
  4. Baja un poco y haz clic en el botón verde Commit changes..., y luego confirma haciendo clic en Commit changes en la ventanita que aparece.

Paso 3: Activar GitHub Pages para publicar tu web

  1. En la parte superior de tu repositorio, busca y haz clic en la pestaña Settings (Configuración, tiene el ícono de una tuerca).
  2. En el menú de la izquierda, busca la sección Code and automation y haz clic en Pages.
  3. En la sección Build and deployment > Branch:
    • En el menú desplegable que dice None, cámbialo a main (o master, según cómo se llame tu rama principal).
    • Deja la carpeta en / (root).
  4. Haz clic en el botón Save (Guardar).

Paso 4: ¡Listo! Visita tu sitio web

  1. Espera un minuto o dos para que GitHub procese los archivos.
  2. Recarga la página de Settings > Pages y verás un mensaje arriba que dice: "Your site is live at..." seguido de un enlace. ¡Ese es el enlace público de tu index.html!

Método 2: Usar Git desde tu computadora (recomendado para proyectos)

Si prefieres trabajar localmente con tu editor de código favorito (como Visual Studio Code):

  1. Crea una carpeta en tu computadora para tu proyecto y dentro crea tu archivo llamado index.html.
  2. Abre la terminal o consola en esa carpeta y ejecuta los siguientes comandos uno por uno: 
    # 1. Inicializar git en la carpeta
git init

# 2. Agregar tu archivo index.html
git add index.html

# 3. Guardar los cambios con un mensaje
git commit -m "Primer commit: subiendo index.html"

# 4. Vincular tu carpeta con el repositorio que creaste en GitHub (reemplaza la URL por la tuya)
git remote add origin https://github.com/tu-usuario/nombre-de-tu-repo.git

# 5. Subir los archivos a la rama main
git branch -M main
git push -u origin main
  3. Una vez subido tu código a GitHub mediante estos comandos, solo debes seguir el Paso 3 del método anterior para activar GitHub Pages en la configuración de tu repositorio y tu página estará en línea.
